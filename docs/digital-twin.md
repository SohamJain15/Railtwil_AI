# Digital twin

**Input:** validated infrastructure, timetable, trains, constraints, and scenario events.  
**Processing:** SimPy advances an independent simulation clock while trains acquire blocks, junctions, and platforms.  
**Output:** changing train/resource state and occupancy history.  
**Assumptions:** track-level topology is a simplified approved prototype representation.  
**Limitations:** no signalling, interlocking, or real-time railway feed is connected.
